# 项目内按需 Skill

图片细节方法从常驻角色提示词移到独立技能包。总控不必一次加载全部资料，也不需要在用户全局 Codex 中安装这些项目技能。

## 使用入口

总控讨论 → 成员 → 对应 AI → 按需技能。可以查看系统方法、审核要点和参考章节，为当前剧本填写制作/审核补充，停用技能，查看历史并载入为新版本。更改从下一轮执行生效。

“版本与执行”中打开具体执行，可查看实际读取的技能、系统版本、自定义版本、章节、理由和当时的正文。目录里出现不代表已经读取；旧执行没有记录时如实显示。

## 内置技能

| 技能                 | 内容                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| drama-text-to-image   | 短剧文生图助手；人物、衣装、外景、室内、装备、载具、生物、特效、静帧、插入图按需分章 |
| visual-style         | 题材与画风；按需参考写实/影视 CG、动画/插画、科幻/奇幻/非人角色、现代/历史 |
| character-reference  | 人物定稿、白色基础服 A-pose、正侧背与身份一致性                            |
| face-expression      | 五官、表情强度、视线、妆容、不同画风的肤质                                 |
| hair-grooming        | 现代短发/卷发、历史束发、胡须与毛发                                        |
| pose-contact         | 左右、肢体、手指组合、握持、接触和承重                                     |
| costume-material     | 剪裁、层次、纹样、织物/皮革/金属及换装参考分工                             |
| lighting-composition | 景别、机位、视觉重点、光向、焦点与色彩分离                                 |
| environment-props    | 场景表演区、出入口、布局与独立道具                                         |
| image-revision       | 看原图、定位缺陷、明确修改与保留、核对副作用                               |

题材与媒介分别选择：现代也可二维，科幻也可写实。覆盖不同性别、年龄、肤色和体型，不将年轻女性/古风词表作为通用默认。非人结构按既定解剖处理，但不能绕过工具图种限制。保留单图单用途、角色规范图与服装分离、节点独立审核及总控权限。

源包位于 `src/server/ai/skills/<id>/SKILL.md`，包含标准 name/description；审核要点在 `review.md`，题材与画风另有四份 references。来自此前研究的取舍及本项目归纳，不是网络原文合集。

## 加载与存储

- `read_skill` 按角色授予，总控及相关图片/分镜节点有目录；原作、剧本和原作审核不注入图片技能。
- 运行开始只提供启用技能的名称、说明和版本。AI 根据任务选 id 并填写 reason；先读主体，再按白名单读取必要 reference，不额外增加一次模型路由请求。
- 制作方收到制作方法，独立审核和总控收到审核要点；分镜读取不增加生图工具权限。
- SQLite schema 17 新增 skill_releases、skill_documents、skill_selection、project_skill_versions、run_skill_loads。源包首次以技能版本 `2026-09-21.1` 入库，运行时只读数据库，不从任意磁盘路径加载。
- 目录及自定义版本号随 run_prompt_snapshots 冻结。第一次实际读取也使用该版本，后续编辑或停用不改变已开始轮次。读取正文和理由持久化，同一轮重复读取同一章节复用记录。
- 拒绝跨项目、非当前执行、越权身份、禁用项及伪造章节/路径。自定义只追加内容，不扩大权限；保存支持冲突检查、幂等，恢复历史产生新版本。
- 常驻规则 `2026-09-21.11` 将资产制作的长细节段替换成目录使用说明；旧规则、自定义与执行快照保留。

## 验证与限制

9 个源包通过 skill-creator 校验。测试覆盖摘要与正文分离、身份/项目/路径限制、分角色内容、按需参考、幂等、自定义冲突、停用恢复、升级后旧轮次首次读取，以及运行时工具接线（测试连接，不发真实 AI 请求）。

独立预览验证保存、停用、从历史恢复及执行读取记录。桌面 1280 和手机 390 宽度检查 DOM 布局，手机输入字体 16px、编辑区 309px、页面无横向溢出；导航标签保持单行可横向滑动。截图接口超时，未完成像素级验收。

没有生成实验图片或启动正式项目 AI，软件检查不等于生图质量已提高。
