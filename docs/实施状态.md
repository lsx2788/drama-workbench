## 已实现

- Next.js 中文网页：项目展开后仅有制作流程和故事资产库两个入口。流程图点击打开节点详情与聊天；资产库聚合全部故事文稿、设定、素材、讨论重点和制作记录。
- 独立 SQLite 表保存项目、文稿修订、流程节点与依赖、节点 AI、Skills 注册和绑定、Session、Message、Highlight、Item、Asset/Version/File、来源/使用、Review、Run 和审计。
- 资产属性精确查询，20岁/40岁等形态可共存；候选上传文件、定稿校验、明确批准范围、多来源组合和双向追溯。
- 事项输入绑定已定稿版本；来源和跨项目范围检查。
- 会话保存内部/外部 ID，支持同一 AI 会话接续；主对话持久化、引用、提取节点重点。
- 点击流程节点可查看已有聊天、最近消息和参与 AI，在节点内添加并直接打开聊天框；添加聊天只展示该节点 AI。故事资产库可查询同一份会话与重点记录。
- 重点独立存储，提议/确认/替代有明确状态，保留源消息和旧结论。
- 人类到子 AI 的写入由 API 拒绝；子会话只读。未接入 provider，不允许网页伪造子 AI 发言。
- 执行请求幂等、配置和上下文快照；未接入执行器时真实标记 blocked。
- 所有素材和数据库不进入 Git。标准 API 不接受任意磁盘路径。

## 第一版使用路径

1. 创建项目并保存故事大纲。
2. 流程草案、总控和专业节点、节点 AI 与事项通过接口登记；真实执行器接入后由 AI 根据讨论结果调用。
3. 网页查看流程图与节点信息，在已有节点建立聊天、讨论和确认重点；待审核事项可确认结果。
4. 登记资产、创建候选、上传文件、审核发布；组合候选引用明确来源版本。
5. 创建事项时绑定正式输入，查看上下文，保存执行请求。未连接模型时请求被标记为阻塞。

这是一轮核心底座实现；并非已经可自主制作整部短剧的完成产品。

流程支持渐进搭建：新建项目只生成总控节点及空会话；已发布流程可以追加普通节点与分组。季可选，分集步骤可为空，前期与归档均不必预建。补充步骤保留原会话、成果和普通依赖，归档门槛按新增内容原子补充并审计；归档已开始时拒绝扩展，空分集不能跳过归档检查。
