# 手机远程访问

连接路径：手机 HTTPS → Cloudflare 临时隧道 → 本机密码网关 127.0.0.1:3100 → 工作台 127.0.0.1:3000。手机不需要与电脑连接同一 Wi-Fi，也不需要安装客户端。电脑须保持开机联网，休眠或关闭隧道后无法访问。

## 启动与关闭

1. 从 [Cloudflare 官方下载页](https://developers.cloudflare.com/tunnel/downloads/) 下载 Windows 64 位 cloudflared，保存到项目的 `data/tools/cloudflared.exe`。
2. 在项目目录执行 `npm run build`，再执行 `npm run remote`。如果已有工作台在 3000 端口运行，会复用；否则启动本机生产服务。
3. 隧道输出随机 HTTPS 地址。用户名、随机密码、地址与进程编号保存在本机 `data/remote/access.json`，不会写入日志或提交 Git。地址写入仅表示已分配，需等待日志出现 `Registered tunnel connection` 并实际访问验证。
4. 手机浏览器打开地址，在浏览器弹出的认证框输入用户名和密码。内嵌浏览器未弹出认证框时，使用系统浏览器打开。
5. 在运行 `npm run remote` 的终端按 Ctrl+C 关闭网关和隧道。由该脚本启动的工作台也会关闭，原先独立运行的工作台继续运行。后台启动的实例由启动者停止对应进程及其子进程。

每次启动重新生成密码和地址。不要直接把隧道指向 3000 端口，否则绕过网关。如果本机工作台配置了 `WORKBENCH_TOKEN`，须在启动远程脚本的环境中设置相同令牌；网关会代为添加，不向浏览器返回令牌。

## 访问边界

网关对页面、静态文件、API 和资产下载统一认证。只有固定本机上游可访问；先校验公网 Host 和 Origin，再转换为本机同源请求，保留后端的来源保护。远程密码不会转发给工作台。共享密码的持有者能够操作当前工作台全部项目，此功能不是多人权限体系。

此临时入口使用 [Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)，适合开发预览，没有可用性保证，不支持 SSE。当前工作台尚未接入模型流式回复；后续接入需更换支持流式通信的部署方式。不同手机运营商对该域名的可达性须以手机实际访问为准。
