# 映序 · Drama Workbench

面向 AI 短剧制作的项目底座：以流程节点组织 AI，以明确版本管理成果，以持久化重点记录代替反复翻聊天。

## 本地运行

要求 Node.js 24.11+，npm。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:3000 。首次启动自动创建 SQLite 数据库。没有自动插入假项目；可在界面创建项目。

新项目只有总控协调、总控 AI 配置与空聊天。其余流程由后续讨论逐步确定，经接口追加到当前流程；分集可先建空入口，前期和归档也可稍后定义，无需提前套用完整制作模板。总控 AI 尚未连接执行器，聊天只保存真实用户消息。

项目目录展开后只有“制作流程”和“故事资产库”。前者展示一张可点击的流程图，点击节点打开信息和聊天；后者先展示分类文件夹，打开后仅查看和搜索该类资料；人物、场景、道具、组合、制作资料与图片/音频/视频分别存放，讨论和事项放在项目记录区。

运行 `npm run seed:demo` 可创建“示例 · 青禾剑录”：包含从故事定位到审核归档的 16 个节点、演示剧本及带来源关系的资产规范。重复运行不覆盖已有资料。示例仅保存实际文字文件，未制作的图片、音频、视频保持候选需求，不伪造执行记录。

```sh
npm test
npm run typecheck
npm run build
npm start
```

## 技术选择

- TypeScript + Next.js App Router + React：网页与标准 HTTP API 共用业务服务。
- Node.js 内置 SQLite：本机无需单独启动数据库。SQL 与文件存储封装在服务层，未来迁移 PostgreSQL 需要显式迁移，非无成本切换。
- 本地文件存储：数据库保存相对文件键和元信息，API 提供文件访问。未来替换为对象存储。
- Zod 校验输入，Node test + tsx 验证业务不变量。

## 代码组织

- `src/app`：页面入口和 HTTP 适配，不放业务规则。
- `src/components`：项目目录、流程图、节点详情与聊天、故事资产库分别维护；复用表单与选择组件。
- `src/client/story-records.ts`：聚合各类已存记录供资产库查看，不建立重复存储。
- `scripts`：可重复执行的演示项目创建脚本与故事数据。
- `src/server/*-service.ts`：按业务边界管理校验、状态推进、项目范围和事务。
- `src/server/db.ts`、`migration.ts`：数据库访问和结构初始化。
- `src/client/api.ts`：浏览器请求与返回类型。
- `tests`：真实临时数据库上的业务规则和 HTTP 适配测试，不接触项目数据。

核心约束写入 AGENTS.md。新增功能先落实到独立业务服务，再接接口和页面；后续模型执行器单独实现，不嵌入页面事件。

Node.js 当前对内置 SQLite 仍会显示实验性提示；这是首版本地部署的明确技术取舍。

数据库和素材位于 data/，不上传 GitHub。DATA_DIR 可修改目录；同时备份数据库与 files/，备份前停止服务。

## 范围

当前实现范围及已验证能力见 docs/实施状态.md；设计全案见 [方案](docs/方案.md)，接口见 [API](docs/API.md)。

第一版仅绑定 localhost，不带团队鉴权。WORKBENCH_TOKEN 可保护 API（请求使用 Authorization: Bearer），设置后网页需自行携带令牌；没有登录界面。不要直接暴露公网。

手机流量临时访问可使用带密码的独立网关和 Cloudflare Tunnel，启动、关闭与限制见 [远程访问](docs/远程访问.md)。该入口保护整站；共享密码不等于团队账户权限。

AI 身份、能力配置、会话和执行记录是持久化基础设施。未配置真实执行器时，发送消息只保存消息，运行状态为 blocked，不产生假 AI 回答。不会使用 Codex/ChatGPT 浏览器登录凭据替用户调用模型。

制作流程采用可扩展的总分总结构：共用前期 → 分集/章节 → 汇总交付。面板无缩放或适配按钮，点开一集查看其制作节点与聊天。可运行 `npx tsx scripts/structure-qinghe.ts` 将未开始的青禾剑录资料整理为三集结构，迁移先备份数据库并保留原节点、会话和资产编号。新集/章节通过 `POST /api/v1/projects/:p/units` 扩展。

总图为一张纵向连线图，支持可选的季层级；季通过 `POST /api/v1/projects/:p/seasons` 定义，扩展分集时可指定 `seasonId`。点击总控查看项目信息，点击某集进入其内部流程，归档保留在总图末端。未归季的项目直接从共用流程展开到各集。
