# 场景与道具
## 输入依据
实际镜头、表演区、机位、场景布局/道具原图与剧情状态。可复用对象先查询基准。
## 制作方法
场景明确前中后景、可站立地面、出入口、尺度和固定参照物。现代办公室、古代庭院、飞船舱室等先满足行走与表演空间；宏伟远景不能代替近景落脚区。多机位保留布局和主光来源。
基础无人场景不擅自加入人物或剧情动作。风化、污损、雾、植被、科技装置等遵循场景状态，不能因氛围盖住关键出口与物件。
道具明确形状、比例、材料、接触/握持部位与剧情状态。金属、木材、织物、塑料的高光与边缘有区别，重要部件不要悬浮。需读的文字才逐字核对；无文字需求不加随机标牌与水印。
奇幻/科幻按确定世界规则保持功能与结构；一张独立物件图不拼入人物、场景和多段特效。
## 正反例与检查
正例：人物要从门口到案桌，保留完整走道和可对照的门桌位置。
反例：用一张远山宫殿大全景声称能直接支持室内近景。修正：按真实表演区补独立场景任务。
