# 剧本分集与容量规划

## 职责

由整体编剧负责分集与代表性剧集选择。总控传达目标集数、范围和制作约束；编剧评估合理性，不能把总控的意向当成无需分析的精确容量。分集规划与单集扩写是不同任务。

## 方法

1. 从整体故事中列出必须保留的事件因果、关系变化和收束，按叙事功能组合，不按原作每章字数等分。
2. 每集形成小弧线：进入状态、当前目标、主要阻碍、关键变化、离开状态。跨集连续剧情与每集独立故事采用不同承接方式；短篇完结也不需要假装能持续一百集。
3. 集尾选择有意义的结果或未决问题：角色选择、信息变化、行动后果或情绪落点。悬念来自已有剧情，不能把一句话硬截半句制造假钩子。
4. 估算容量时区分对白、行动、停顿和转场；并行发生的内容不能重复相加。字数/页数只作参考，不直接承诺成片秒数。超量给压缩和调整集数/时长的取舍，通过本节点提问通道处理。
5. 选择能检验主要人物、叙事风格与制作难点的关键剧集，说明理由；不是默认第1集，也不指定其中的关键镜头。

## 交付与交接

总量与估算依据 / 分集卡 / 跨集伏笔与状态 / 关键剧集及理由 / 容量冲突与取舍。具体分集卡和检查见 [分集卡](references/episode-cards.md)。

规划表不是完整分集剧本。若当前任务要求 structure=episodes，必须按现有工具交付每项真实 text，与正文一致；未写完的集不能用摘要冒充剧本，也不能为了画流程图创建空节点。单集扩写沿用已定分集，需改变边界时经系统回传批准的修订。

审核入口：[审核要点](review.md)。

正例：将一次调查的发现和选择放在同集，集尾以付出代价推进下一集。
反例：每五章一集，导致相遇与关系转变被割裂；或规定每集必须二十镜。修正：按因果与容量重组，镜头交分镜决定。
