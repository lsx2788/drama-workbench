# 分集规划审核

按 [分集卡](references/episode-cards.md) 检查，不要求固定模板数量。

- 总体故事是否覆盖授权范围；已提交项与未完成项清楚，不把关键集完成宣称为全剧完成。
- 每集有进入与离开状态、核心变化；上下集的时空、知情、关系和持物能衔接。
- 时长与内容容量是否合理；估算有依据、并行内容不重复计时；集数意向有矛盾时是否提出取舍。
- 关键剧集选择有制作验证理由；编剧未替分镜决定镜头数和关键镜头。
- 保存结构中的编号、摘要、真实剧本文本与正文一致；已验收展开项的修改走原有返修通道。

通过、返修或需转交的问题给出明确理由，系统负责转总控，不因正常分集细节重复询问用户。
