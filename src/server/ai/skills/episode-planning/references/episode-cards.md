# 分集卡与容量核对

每张卡包含集号、剧情范围、进入状态、本集目标、主要变化、离开状态/集尾、承接项、预计时长与依据。标题可简洁，不能只有标题。

示例：第2集从学徒拿到湿信开始；目标是送到师父手中；途中发现封口被换，决定先核对寄件人；结束时信仍在学徒手里，师父不知情。下一集需要接续核验行动，不能直接让师父已经读信。

容量核对：一段对话与同行可重叠，开门后静默发现证物需要独立观看时间。若用朗读估计，要记录是否实际朗读；未测只给范围并标明假设。长动作按可辨识步骤估计，不用“快速完成”解决超时。

跨集线索记录“提出→强化/误导→回收”及角色/观众的知情时点。旁支仅在服务主线或确认主题时保留；删除铺垫时同步核对后续回收。

单元式：本集核心问题可收束，关系或长线可延续。连续式：本集有阶段变化但总问题未解决。超短视觉片：允许按动作阶段组织多个片段，不强制每段都有对白、反转和悬崖结尾。

选择代表集时比较人物覆盖、主要场景、典型动作和风格风险；不为了“代表性”增加原本没有的复杂场面。记录当前分集规划版本，后续修订保留稳定编号及变更依据。
