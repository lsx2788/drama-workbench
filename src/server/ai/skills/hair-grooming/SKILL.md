# 发型与毛发
## 输入依据
发际线、分缝、长度、发量、发色及已确认造型；胡须/体毛/动物毛发按实际角色需要。
## 制作方法
先说明轮廓和大束走向，再选发根蓬松、脸侧发束、发梢收束和少量碎发。短发重顶部与鬓角轮廓；卷发明确卷度、尺度与成组方向，不让每束都像同一弹簧。
束发明确扎束/发髻位置、数量和形状，饰物独立限定；传统名称不能替代结构，也不能作为历史准确性保证。科幻角色剃发、染色、植入件以基准为准，不默认增加。
写实用适度发束层次和局部反光；二维保持清楚色块与线条；三维避免整块塑料高光。毛皮顺身体体块与生长方向变化，不在所有位置铺同样长度。
规范图不加风吹遮脸；动作图中毛发与衣摆受风方向一致。返修局部发丝时锁住发际线、分缝和整体轮廓。
## 正反例与检查
正例：低马尾束点保持后颈上方，只调整脸侧一束遮眼头发。
反例：“华丽”自动新增高冠、珠串；“自然”自动改变卷发为直发。修正：饰品与固定发型分别控制。
