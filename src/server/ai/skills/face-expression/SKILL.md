# 面部与表情
## 输入依据
身份基准、当前景别、剧情情绪与强弱、主光方向。脸型/眼距/鼻唇比例固定，表情和妆容按任务变化。
## 制作方法
先定一个瞬间与情绪强度，再挑少量关键部位：视线目标、头部角度、眉心、眼睑、嘴唇闭合。克制担心可写眉心轻收、看向对方、嘴唇轻闭，不自动叠加流泪瞪眼张嘴。
近景才细化眼形、虹膜与眼神光、睫毛疏密及妆容部位/浓淡；高光与主光对应。写实皮肤用局部纹理、色差和柔和转折，不全脸油亮或强磨皮，不新增痣疤和年龄特征。二维按既定线条与色块表现，不强加毛孔。
保持不同性别、年龄、肤色和既定面部特征；妆容不是女性默认要求，胡须、皱纹等来自角色。近景清楚呈现五官，艺术性裁脸、遮挡与浅景深须适合独立用途。
## 检查与正反例
正例：仅减弱面颊过大亮斑，保留肤色和原有面部转折，其他特征不变。
反例：用“瓷娃娃、真人毛孔、全脸湿亮、强磨皮”同时修脸；或一张图要求先哭后笑。修正：选定媒介和当前表情，局部调整。
