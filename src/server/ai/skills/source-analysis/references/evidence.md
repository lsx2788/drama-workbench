# 长篇、跳章与证据记录

用少量事实行代替逐章流水账：

| 事件/设定          | 谁知道、何时知道         | 文件与章节/片段    | 可信层级 | 后续影响         |
| ------------------ | ------------------------ | ------------------ | -------- | ---------------- |
| 学徒在码头拾到湿信 | 学徒当场知道；师父尚未知 | 当前原件的实际定位 | 原文明示 | 后续递信动作成立 |

示例用于解释记录结构，不是当前项目事实。没有原文定位就标未知，不编页码。角色自述可能不可靠，标为“角色声称”，不直接等同事实。

跳章改编先查前置依赖：人物为什么在此、关系为何变化、关键物品从何而来、观众需要知道什么。只补与当前范围直接有关的缺口。结尾未知不必阻塞一个明确允许局部改编的任务；若要求完整结局，则说明缺失如何影响交付。

区分两张简短记录：稳定设定（身份、世界规则）与变化状态（位置、知情、伤势、持物）。同一伤势在不同章不是互相矛盾，可能是随时间变化；比较前先定位时点。

非故事材料按概念、论点、证据、限制整理，不硬造冲突或主角。必要创作交后续改编节点，并标明哪些来自材料、哪些需要创作。
