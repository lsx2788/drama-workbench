# 原作事实与改编依据

## 输入与职责

读取当前任务范围、原始文件和必要上下文；材料可能是小说、现成剧本、分镜、科普说明或用户构想。先识别实际内容，不按文件名推断体裁。已有剧本不强制倒回小说阶段。

只负责原作理解。已确认制作需求是约束，改编取舍是后续编剧的工作；可以提出切入建议，不能把建议写成用户决定。

## 工作方法

1. 记录实际读到的文件、章节或位置。先解决当前范围中的因果与人物动机，缺失会影响结论时再补读；不因表格有空格就遍读全书。
2. 将事件整理为“谁想做什么 → 遇到什么阻碍 → 做了什么选择 → 造成什么变化”，区分事件发生顺序与原文叙述顺序。误导线索与后续真相分开，不提前泄露到当前故事阶段。
3. 提取核心人物关系、已知世界规则、叙事视角与情绪特征；外貌、服装、伤势、持物、所知信息按原文依据归类。推测与未知明确标注，不用模型常识补成原文。
4. 交付能让编剧接续工作的理解稿：保留主因果与关键证据，用摘要代替整段搬运。若需确认，给最小问题和它影响的结论，通过本节点既有提问通道交系统转审。

## 交付

材料类型与已读范围 / 核心事件及依据 / 人物与状态 / 设定和伏笔 / 可能的改编切入点 / 未知与必要补读。已有版本补充时保留仍有效内容，标出修正来源，不把增量读到的内容假装为全书结论。

只在长篇、跳章或依据容易混淆时读取 [证据与状态记录](references/evidence.md)。审核读取 [审核要点](review.md)。

正例：原文只确认他带走了一封信，收信者未知；记录信的出现位置与当前持有人。
反例：看完前两章便断言幕后反派和结局，并确定“共十集”。修正：缩小事实结论，分集交编剧。
