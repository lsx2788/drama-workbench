# 布光与构图
## 输入依据
用途、画幅、景别、项目画风、场景布局、主要视觉信息。先决定观众应看什么。
## 制作方法
明确正侧视角、机位高低、主体画面比例与焦点。全身图头脚完整，面部近景五官可读，规范图同尺度与稳定照明；不能一图同时要全身完整和极近毛孔。
主光注明画面方向、柔硬、暗侧保留程度；必要时用克制的轮廓分离。浅衣浅背景保留褶皱和边缘，深发暗背景看清轮廓。环境底图、角色合成的光向和色温需一致。
综合色调不改变固定发色、眼色或衣色。二维/插画用适合媒介的阴影与色块，不强加摄影耀斑；真实场景中光影要和光源/接触对应。
焦段、光圈或电影感是视觉意图，不是图片真实元数据；分辨率以文件为准。浅景深只在任务适合时使用，不能让规范图关键部位模糊。
## 正反例与检查
正例：左前方大面积柔光，右侧暗部保留脸部体块，白衣轮廓与浅灰背景可分。
反例：同时要求平光无影、强侧逆光和全画面极浅景深。修正：选一个明确主光结构和主体焦点。
