# 姿态与接触
## 输入依据
本次静态瞬间、角色解剖、身体朝向、道具与实际参考。区分人物自身左右和画面左右。
## 制作方法
先定重心、支撑脚、躯干倾斜与四肢关系，再描述手部：哪只手、掌心朝向、手指组合、接触目标、手腕/前臂位置、道具朝向。
握持、托举、触碰有不同受力与遮挡；检查物件大小、接触点、脚底站位和物体穿插。允许自然遮挡，不强求五指全露；非人角色遵循既定肢体和关节。
例：右肘弯曲，右手在胸前，食指与中指并拢朝上，其余指自然收拢；这不同于伸臂向前指。两手握同一柄不同于左手托右腕。普通握持不默认加青筋和发白指节。
一张图表达一个状态；跑、跳或飞行需说明当前离地/落地/支撑关系，不在同一图里放多个阶段。动态参考不能混入基础 A-pose 规范图。
## 输出与检查
明确动作主体、接触、支撑和应保持部分；只检查当前景别可见的关系。
反例：只写“自然持物”而缺少物体方向，或双脚悬空却声称站稳。修正：补充具体结构与支撑依据。


## 审核入口
