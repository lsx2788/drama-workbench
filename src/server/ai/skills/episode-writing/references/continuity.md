# 跨场跨集连续性

只记录影响剧情的状态：时间与位置、人物知道什么、关系与承诺、伤势、持物、服装阶段、未回收线索。稳定设定与当前状态分开。

| 状态               | 本集进入 | 改变依据             | 本集离开               |
| ------------------ | -------- | -------------------- | ---------------------- |
| 信的持有人         | 学徒     | 桌前未交出，最后收回 | 学徒                   |
| 师父是否知封口异常 | 不知     | 学徒当面说明         | 已知异常，寄件者仍未知 |

同一场景换地点、跳时或闪回要让读者定位。人物换衣、伤势好转或道具易主需要合理剧情依据；无关细节可以省略，不为每一粒纽扣建表。

返修先列受影响范围：修改一场里“把信交出”，会影响后场持物和知情；仅润色一句不改变含义的对白，不应使全剧自动重写。尊重正式版本与稳定编号，不能直接覆盖其他节点已验收内容。

未知前提如果影响当前行动，用明确问题说明“缺什么、导致什么不能确定、建议查哪段/可选方案”；通过系统现有通道转审，不直接对用户发问。已有答案引用其依据，避免重复确认。
