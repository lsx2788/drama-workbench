# 场景与对白展开

场景最小单元：时空、在场人物、目标、可见行动、对白、场末变化。目标不必写在正式对白里，可作为作者工作说明。

示例：

> 内景·修理铺·傍晚  
> 学徒把湿信放在桌角，手仍压住封口。师父伸手，他将信挪开。  
> 师父：路上耽搁了？  
> 学徒：有人换过封口。  
> 师父停下擦拭工具。门外脚步声近了。学徒收信。

这里通过行动与对话改变双方关系，不用旁白说“他警觉、紧张、怀疑”。该片段是方法示例，不可当原作事实或默认悬疑情节。

对白检查：每句是争取、试探、回避、安抚还是提供必需信息；删掉重复解释和角色不可能知道的内容。人物口吻由年龄经历、关系、职业及当前压力决定，避免所有人同样文绉绉或网络化。潜台词来自目的与表面说法的差异，不等于故意说得晦涩。

声音标注：画面内说话者、画外同场声音、跨时空旁白分别写清；电话或广播标来源。无口型需求的声音不能误分配成画内人物开口。

进出场选择服务信息与情绪，不必须展示所有走路、坐下和开门。动作型段落可以少对白，但必须看懂目标、空间变化和结果。不要沿用英语剧本的“一页一分钟”到中文 Markdown，也不把格式细则当内容质量保证。
