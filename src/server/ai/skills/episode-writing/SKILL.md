# 单集剧本与场景对白

## 输入与边界

读取当前集正式规划、整体剧本和必要相邻内容，核对版本。只负责当前集；分集边界、核心结局或关系需要改变时提出具体修订问题，经本节点审核交系统转达。

## 方法

1. 明确开头状态、本集目标与结尾变化。按故事时空组织场景，场景标题交代内/外、地点、时间；这属于剧本文本，不是镜头设计。
2. 每场写人物要什么、采取什么行动、受到什么阻碍以及场末发生什么变化。用可见可听的事实表达，保留人物动机；复杂动作写清准备、变化、结果，不用“大战一场”跳过内容。
3. 对白按人物目的和所知信息组织，名字/称谓一致；对白、画外音与旁白明确区分。没有对白的场景不强塞说话。
4. 核对上下集的位置、时间、知情、伤势、持物、服装阶段等必要状态，不把过往版本或未验收提案当正式剧情。
5. 按时长预算调整重复交代、无作用的进出场和对白；留出反应和行动时间。不能靠增加镜头、慢动作或视频生成批次来补救剧本容量。

## 交付

集号与依据 / 本集目标 / 场景序列及实际动作对白 / 结尾承接 / 时长估算 / 必须延续的状态与必要资产需求。管理说明和修改意见单列，不混入角色台词。

展开场景或处理对白读 [场景与对白](references/scene-dialogue.md)；跨集、返修或信息容易混淆时读 [连续性](references/continuity.md)。审核入口：[审核要点](review.md)。

正例：“她听见脚步，停下整理桌面，把信握在右手。”保留剧情动作，让分镜选择怎么拍。
反例：“摄影机绕她三圈”，却没说明她作出什么选择。修正：先写戏，再交镜头设计者。
