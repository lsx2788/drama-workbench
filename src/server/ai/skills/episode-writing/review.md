# 单集剧本审核

核对当前集的正式规划、输入版本与必要上下集信息。

1. 每场是否有行动和变化，人物目标与已确认动机一致；没有用不可见心理说明代替关键剧情。
2. 对白有明确说话者，旁白/画外音与口型对白分开；信息量、角色知情和语言风格合理。
3. 开头、结尾及重要状态连续，修改没有悄悄改变全剧边界或已确认结局。
4. 内容容量与预计时长匹配，未编造实测；没有越权拆镜或制作图片。

按问题读取 [场景对白](references/scene-dialogue.md) 或 [连续性](references/continuity.md)。返修定位到具体场景、台词或状态及影响；不要整篇重写审核意见，更不能以个人偏好新增爆点和人物。
