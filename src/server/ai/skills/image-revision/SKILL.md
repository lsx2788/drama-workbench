# 局部返修
## 输入依据
本任务当前版本/退回原因、真实原图、已验收身份或服装参考、最新用户意见与既有权限。先看图片，不能只靠聊天中的形容词猜缺陷。
## 制作方法
按“问题位置 → 期望变化 → 必须保留”组织。只选影响本轮目标的技能，不把各类建议整套追加。多处相关改动可一起说明，重大身份/方向变化仍按系统询问，不自行扩展。
实际引用时为每份文件说明锁身份、款式、材质或当前缺陷，传真实 referenceFileIds；自身历史图可用于自身返修，但不是正式验收基准。
保持原 taskId 与最新 revision；生成保存、送审、失败停止仍由现有系统控制。不能为了换个名字新建重复任务。
如果请求含糊且参考无法判断，明确缺失信息交原有节点问题通道；已明确的局部改动不重复请求相同授权。
## 正反例与检查
正例：减小右脸颊亮斑，保留原肤色、表情、脸型、发型和背景；锁定身份参考，仅编辑当前图片的目标局部。
反例：为修一只手重新设计人物和衣服，或只堆“更完美、绝不出错”。修正：给出具体几何/材质目标并核对副作用。
出图后比较目标区域是否改善，身份、构图和材料有无意外变化；没有实际对照不声称成功率提高。
