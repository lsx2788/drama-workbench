# 分镜审核

审核当前版本与已确认剧本，按本节点职责判断，不重写编剧设定。

- 剧情信息与行动是否覆盖；有无漏掉导致观众看不懂的因果或擅自新增剧情。
- 每镜是否有清楚目的，动作/视线/机位/景别可理解；不把主体移动误写成运镜。
- 镜间轴线、方向、持物、空间与动作阶段是否衔接；有意越轴是否有观众可理解的转换。
- 时长是估计还是实测；对白/动作并行和慢放是否正确计入；本镜是否塞入过多事件。
- 结构编号、代表镜头、正文与提交范围一致；部分分镜不等于全片完成，生成提示词不等于实际视频。

必要时读 [覆盖连续性](references/coverage-continuity.md) 与 [时间交接](references/timing-handoff.md)。将问题按剧情理解、连续性、执行难点排序，定位镜号和前后关系。多种正确镜头方案可以通过，不按审美偏好无限返修。
