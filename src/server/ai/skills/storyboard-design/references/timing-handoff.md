# 时间预算与制作交接

分开记录成片镜头、平台生成片段与后期取用范围。一次生成的时长不是成片总时长，输出成功也不是可用性已验收。

时间估计按可辨识行动、对白/旁白、反应、阅读信息、停顿与转场考虑；动作和对白同时发生时按重叠关系估计。慢放标明实际占用的成片时间，不能先按慢放后时长计入又重复乘倍数。没有试读或试片时写估算范围，不写精确已验证数字。

单镜复杂动作优先保留一个核心事件。连续阶段需要多镜时清楚标起止状态；只有当前职责和范围允许时拆镜。固定构图、清晰动作通常比同时快速运镜和复杂变形更容易检查，但不是所有镜头都必须固定。

交接可列：

- 真实镜号、输入剧本/资产版本及用途；未就绪资产写需求，不冒充可用文件。
- 当前选择文生视频、图生视频、首尾帧或多参考中的哪种方式及依据；平台未知先交平台中立描述，不能猜参数。
- 给模型的内容：主体、一个连贯动作、环境必要变化、相机行为、光色和必要声音。图生视频避免重复重设计输入图身份。
- 放在提示词外的内容：资源编号与平台槽位对应、成片目标/生成长度、后期裁切配音与字幕、待验证风险。

静态图片交单一时刻；视频描述时间变化；首尾帧分别独立成图，不拼成对照板。禁止因为读取 Skill 就调用不属于分镜的生图/视频能力，当前视频仍由人工生成与核验。
