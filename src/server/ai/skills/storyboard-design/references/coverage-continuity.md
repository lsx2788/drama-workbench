# 覆盖、视线与剪辑连续性

根据观众需要选择建立空间、关键行动、反应或细节镜头，不为每场机械补全所有景别。拆镜理由可以是注意力转移、反应时机、时间跨度或空间信息变化；没有理由的重复切镜可以合并。

对话：先让双方相对位置、视线方向可理解，再选择同框或正反打；反应镜头与说话镜头不必逐句交替。动作：交代方向和接触点，关键过程不能只留开始与结果却让观众看不懂怎么发生。悬疑细节：控制观众此刻是否应看清证据，不因特写提前泄底。

轴线是帮助维持方向的参照。需要跨越时，可用连续移动、清楚的重新建立镜头或中性机位说明空间改变；不要把“永不越轴”当教条，也不能用左右翻图替代重新设计。

每镜必要锚点可写：人物自身哪只手、画面哪侧、看向哪个具体地标、物体在哪、动作处于哪一阶段。世界方位和画面左右分开；切到反打后画面左右可能变化，但人物自身右手不能变左手。

示例：镜1同框，学徒在左、师父在右，桌在中间；镜2钥匙近景，仍是学徒右手放下；镜3师父反应，视线朝学徒所在方向。无需再加无剧情作用的屋顶航拍。

本节只设计文字分镜和画面需求；图片参考可交生图节点制作，不在这里生成混合九宫格。
