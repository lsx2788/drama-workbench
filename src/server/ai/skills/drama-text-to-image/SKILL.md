# 短剧文生图助手

将已确定的剧情需要转为可画、可核对、可复用的单图描述。题材与媒介分别选择：现代、历史、科幻、奇幻、悬疑等均可配写实、影视 CG、二维动画、三维卡通、插画等，不默认古风、年轻女性、写实皮肤或固定画幅。

## 编写方法

1. 确认本图用途和可用依据：用户已确认要求、当前任务、原作事实、已有资产。将参考文件逐一对应到身份、结构、衣装、布局或材质；没有实际附图时用可独立理解的文字，不能声称已引用图片。现有资产先看原图再描述，不能只凭文件名。
2. 用自然语言写清“主体及当前状态 → 关键形状/材质与空间关系 → 单一视角和构图 → 光色与媒介”。先写辨识度高、影响剧情的少数细节；弱相关装饰省略。环境描述服务于主体和表演，不让所有物体同时成为焦点。
3. 区分固定项与本轮变化：固定身份、形状、布局和已确定画风；只改变当前要求的视角、服装、光照或损坏状态。全新文生图可以探索外观；已有基准的补图应使用实际参考输入，不能承诺靠重复文字必然一致。
4. 输出简短的用途说明、可直接使用的画面提示词、参考分工及必要检查点。管理编号、审核结论、版本、下一步计划放在画面提示词外。示例只示范写法，替换其题材和细节，不照搬成项目事实。

## 本项目约束

- 一次一个用途、一张独立画面。角色基础三视图可按既定规则展示同一人的正侧背；其他多角度分别制图。禁止人物＋服装＋武器＋场景＋特效混合设定海报、九宫格和前后对比拼图。一个正常镜头可以同时有人与环境，这不等于混合图种。
- 人物按正面定稿 → 白色不透明基础打底服 A-pose 三视图及面部特写 → 独立服装 → 引用二者的穿衣组合推进。章节不能改变现有基准、必需图或审核门控，也不能要求每张补图重新找用户确认。
- 静态图描述一个可见时刻；动作全过程、镜头运动、秒数和转场留在分镜/视频交接中。
- 优先正向描述可见结果。排除项只写当前高风险偏差；若模型不支持独立负面参数，写入自然语言，不伪造 `negative_prompt`、种子、权重或专属命令。输出格式、比例、分辨率以真实工具为准；“8K”“透明背景”写进提示词不证明文件实际具备这些属性。
- 基础资产用清晰、稳定的光照展示结构；只有剧情镜头需要时才增加戏剧性遮挡、强景深或运动模糊。不要把成品海报审美强加给资产参考。

## 审核

使用 [审核要点](review.md)。在项目执行链，系统会按身份返回审核版。Skill 提供图像方法，不授予生图、验收、重做或扩展资产清单的额外权限。
