# 室内、家具与空间连续性

描述一个可走入的空间：房间用途、平面形状、摄影机位置与朝向、门窗和固定家具关系，然后补材料和生活痕迹。世界位置用“入口左侧墙”“背窗一侧”描述；画面位置用“画面左下”描述，两者不要混为一谈。

家具只选影响表演和身份的几件，交代尺度、朝向和通行间隙。书桌/柜台/床与门口之间应有合理路线。既有房间换视角时，补出参考看不到的部分要符合布局；未确定部分说明是设计补全，不伪称从原图看出。

材质按区域分工，如墙面粉刷、地面木纹、金属灯罩；粗糙度影响反射但不等于全屋脏污。光源注明来自窗、顶灯、台灯等及投影方向；夜景可保留低强度环境光，避免基础资产黑成剪影。

示例：温暖三维卡通风格的单间修理铺内部，镜头在正门内朝后墙。后墙中央工作台，两边是低柜；入口右侧靠墙放一辆待修自行车，左墙高窗采光，中央留通道。桌面少量工具按功能分区，木面磨损集中在操作区，墙面浅暖灰；自然侧光，结构清晰的一张广景空镜。

其他类型：医疗/办公室空间用实际用途决定陈设；古代室内核对门窗与家具时代；科幻舱室交代舱门、通道、控制台的相对位置；悬疑气氛通过有限光源和阴影表达，不能靠无限增加杂物。
