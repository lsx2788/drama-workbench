# 载具与驾驶空间

先定载具类型、时代用途、尺度、轮廓、承载方式，再定摄影机和当前状态。汽车、船、马车、飞行器都需要可理解的前后方向、入口和乘坐位置；科幻外观也应有稳定结构，不靠随机机械线条填满表面。

- 外观：车身/船体/机身比例，轮子或支撑位置、舱门、窗、灯和主色分区；强调已确认的识别特征。单视角只核对可见部件数量，不能凭看不到的另一侧判缺失。
- 内部：座椅、驾驶台、门窗和前进方向，人物能否合理落座/出入；已有外观的舱门与内部入口保持对应。
- 状态：停靠、悬停、静止行驶瞬间、门开或闭各选本图需要的状态。静态资产参考保持清晰；速度表现留给剧情镜头，不能使轮廓不可辨。
- 接触：轮胎与地面、船与水线、人物与座位有合理接触；悬浮是明确设定时才无接地。引用已有基准控制涂装、损伤、编号，不靠左右镜像伪造反向视图。

示例：近未来社区配送小车，低矮四轮底盘，浅灰封闭货厢，右侧一扇橙色舱门，前面两盏窄灯；静止停在平整灰地面，前右三分之四视角，车轮着地，货舱门关闭，日间柔光，清晰三维动画风格，一辆车、一张画面。

反例：独立车图同时展示驾驶舱、爆炸、行驶轨迹和拆解零件。修正：按当前用途保留外观或内部一个画面。检查外部开口与内部、前后方向、支撑、轮廓、玻璃反射及附属件归属。
