# 插入图：信件、屏幕、招牌与食物

先判断观众必须看懂什么。承载情节的关键文字、数字、图案与道具状态优先，装饰不能抢占主体；不自动为所有物体生成标签、logo 或说明字。

文字类：准确给出允许出现的原文、语言、行序与所在表面，控制信息量。纸张注明折痕、印章/手写分区和持放状态，屏幕注明边框、屏幕内容与反光，招牌注明字体气质、安装方式和照明。关键字逐字看图核验；生成不准时可交给后期排字，未经完成不得声称可读。

食品类：选已出场的一份食物/一件餐具，说明温度状态、表面纹理、切面或汁液位置、承托与份量感；不要把每样配料悬空炸开。广告式摆盘只在剧情要求时用，悬疑桌面或家常厨房按场景保留真实使用痕迹。

示例：现代剧的一张便笺特写，米白纸平放木桌，仅有黑色手写两行“钥匙在门口”“今晚八点”，右上角一处折痕，轻微侧光，文字完整在焦点内，纸张四边可见；无其他文字、边框拼图或手。

食物示例：三维卡通早餐插入图，一碗热面放在旧木桌上，面条与两片青菜清楚，少量蒸汽上升但不遮碗边，筷子平放碗右侧；单一斜上近景，温暖窗光。

反例：关键短信淹没在整页手机 UI、品牌水印和乱码里。修正：保留当前故事所需的最少文字和必要界面，文字准确性另核对。检查时间、金额等剧情数字、镜像字、溢出、餐具接触与食物状态。
