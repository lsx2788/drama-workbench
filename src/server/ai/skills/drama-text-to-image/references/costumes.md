# 服装与配饰：可以拆开复用的设计

先写时代、地域、职业和季节，再写剪裁轮廓、层次、开合、长度、颜色归属、主辅材质、少数识别细节。历史准确性依实际依据；不凭“古风”混搭所有朝代。科幻服装应能看出穿戴方式，卡通服装保留形状和色块层次即可。

服装独立图选当前能看清结构的单视角：按任务用无人物展示、合适人台或平铺。保持衣身内外、领口、袖型、腰线、鞋与配饰的归属，不让人物脸成为服装图主体。背面特殊结构需要时另图，不能默认一张塞全套拆解。

材质靠具体行为表达：棉布柔哑且褶皱宽缓；薄纱半透与叠层边缘；缎面宽而连续的亮带；皮革折弯与磨损；金属窄高光与硬边。透明只属于指定外层，不能令内衬和身体一起透出。饰品说明挂点、垂向、大小，避免悬空。

穿衣组合明确参考分工：人物图提供脸、身体与发型，服装图提供衣装；合成后检查衣物贴合、肩腰受力、手臂遮挡和统一光照，不将服装参考中的人台脸带入角色。

示例：近未来维修工作夹克，短立领、宽松直身、肘部织物补强、左胸一条橙色识别带，深灰哑光布料与少量磨砂金属扣。独立正面衣装图，素净背景，袖口与下摆完整，软侧光显示裁片，不添加武器或模特。

反例：把“轻盈”只变成高亮塑料、再加很多珠宝。修正：从重量、垂坠、层间空气和具体材质说明轻盈。检查领口与袖口、层次、配件数量及后续穿戴是否可读。
