# 装备、工具与道具

先锁定剧情用途与辨识形状，再补材质和细节。现代手机、手提箱、证物、古代器具、兵器、盔甲、科幻设备都用这一方法，不自动变成仙侠法器。

1. 大形：尺寸感、长宽比例、整体轮廓、主要组成部分、握持/穿戴/放置方向。武器只描述影视外观和可见结构，不需要制造参数；盔甲说明覆盖部位与活动间隙。
2. 材质：明确哪部分是金属、皮革、木头、陶瓷、玻璃、布料；磨损集中在触碰和受力区，别把所有表面涂满锈和发光纹。
3. 状态：开/关、完整/破损、出鞘/入鞘等只选当前状态。设备打开后露出的内部是同一件物品的一部分，不再复制一件放旁边。若剧情有暗记、证据纹路，决定是否需要另做特写。
4. 展示：独立资产采用能读清轮廓的单视角与简单背景，长物体头尾完整，边缘与背景分开。由具体设计决定对称性；不能对一切物品强行“完全对称”。握持图另按对应任务引用角色参考。

示例：现代悬疑剧证物，一枚旧黄铜钥匙，短椭圆钥匙环、扁平柄部、两级缺口，柄端一处细划痕；单件放在灰色证物垫上，斜上方近景，铜面暗哑，常握处略亮，轮廓完整，无手和说明标签。

科幻示例：掌上环境扫描器，圆角矩形深灰外壳，顶部折起的小型探头、正面窄显示窗、侧面橙色橡胶握持区，关机状态；单一三分之四视角，磨砂塑料与金属分区可见，白灰背景。

反例：一把剑旁堆满不同剑柄、光效状态和角色动作。修正：只做当前兵器外观，其他用途拆开。检查整体轮廓、零件归属、可握持位置、关键数量、损坏位置和真实参考一致性。
