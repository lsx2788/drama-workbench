# 特效、天气与元素图

明确本图是特效形态参考、可合成素材还是剧情画面。先说明源头/附着点、单一时刻、运动方向的静态迹象、范围与强弱，再说明颜色、密度和环境响应。火、水、烟、雪、电光、魔法均如此；单张静帧不宣称已经完成动画或粒子系统。

- 形态：火焰由接触物延伸、烟由源头向上或随风偏移、水花有撞击点与重力方向；魔法可超现实，但应符合当前世界设定和前后造型。
- 层次：核心、外缘、少量尾迹各有明暗，避免所有层都过曝发白；烟/雾有厚薄与局部遮挡，不把主体完全吞没。
- 空间：元素在主体前或后、遮挡哪些区域，发光是否影响邻近表面；特效颜色别污染本应固定的衣服和脸。
- 独立素材：画面边缘留够余量，背景按真实合成需求选择。黑底发光、纯色背景都不是透明 alpha；交付透明图须核对实际通道，不能画棋盘格假装透明。

示例：奇幻短剧的单股淡青色风刃形态参考，主体为向画面右侧弯曲的薄弧，中心亮度适中，外缘逐渐变淡，少量细碎尾迹留在左侧；独立单元素、深灰背景、形状完整，不加人物、武器、场景或文字，不拼不同阶段。

写实替换：雨滴撞击地面的一个瞬间，水花以接触点为中心向外、湿地反射低对比。悬疑替换：走廊近地薄雾，门和行动区仍清楚，不需要通体荧光。

反例：一张图要求火球形成、爆炸、消散三个阶段。修正：选当前目标时刻，其他阶段另按任务处理。检查源点、附着、遮挡、范围、光影响和后续合成可用性。
