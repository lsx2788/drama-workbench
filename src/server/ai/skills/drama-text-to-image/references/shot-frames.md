# 镜头静帧与人物入景

按已确认分镜执行，不在此重写剧情、镜头数量和关键镜头。先确定这张图承担首帧、尾帧、动作姿态还是最终画面的哪一种用途，然后只描述一个时刻。

1. 主体：谁在做什么可见动作，重心、手脚、眼睛看向哪里；多人时用具体衣装/身份与画面位置区分，不用模糊的“他在他身后”。避免一句话包含连续三次动作。
2. 空间：角色与场景地标、道具的相对位置，前后遮挡、接触面、视线及运动轴线；已有镜头的左/右延续依分镜，不能擅自翻转。
3. 相机：景别、机位高低、观察角度、主体留白和清晰区域。焦距术语只在有帮助时使用，避免同时写极广角透视、正交和无畸变。图像画幅沿用实际制作要求。
4. 融合：实际参考中身份、服装、道具、布局各有分工，统一光向、透视、比例、脚底阴影与反射。背景人物只在任务需要时出现；不要把独立资产的白底带进成片。

示例：现代悬疑分镜的近景静帧，调查员坐在桌子左侧，右手将已确认的钥匙放到桌面证物垫上，指尖尚与钥匙环接触；对面的同伴只在右前景露肩部，焦点在钥匙与手，调查员脸部仍可辨。灯光来自桌面左上方，沿用原房间布局与角色衣装，单张画面。

反例：“镜头推近，他拔剑、回身、跳上屋顶。”修正为分镜要求的一个可见节点，如右脚已踏上台阶、手尚握剑柄；运动和时长单列视频交接。

检查身份/服装是否串图、手指和道具是否穿透、脚是否承重、画面重点是否清楚。多个参考合成一个正常镜头允许；把不同阶段并排拼成故事板不符合本次单图用途。
