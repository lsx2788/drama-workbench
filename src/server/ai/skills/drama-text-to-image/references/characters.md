# 人物：身份与身体结构

确定年龄阶段、体型、身高比例、脸型、眉眼鼻口的辨识特征、发际线及发型大轮廓；用可见特点表达气质，例如下颌轻收、平视、肩部放松。不要仅写“绝美”“高级脸”，也不默认瘦、白、年轻。

正面定稿与基础三视图：不透明白色简洁合体打底上衣与裤装，轮廓清楚但不紧勒，非礼服、裙摆或盔甲；中性 A-pose，双臂略离躯干斜向下，手指自然分开，双脚稳落同一地面。不是夸张展翅或大幅 T 字举臂。三视图正面、正侧面、背面等尺度，同姿态、同发型，完整头脚；基础服不继承剧情衣装。

面部特写另成单图：眉眼与嘴角状态、视线方向、表情强度清楚，避免发丝遮住关键五官。不同表情保持眼距、鼻唇比例与骨相。二维角色用稳定线条与色块，写实才写对应皮肤纹理；不要同时要求瓷娃娃无纹理与毛孔纤毫毕现。

示例：现代悬疑剧中的五十岁男性调查员，宽下颌、略高发际线、短灰黑发，肩宽、腹部自然；白色基础长袖和直筒裤，正面全身 A-pose，平视，中性浅灰背景，均匀柔光，写实影视 CG，头脚完整。

反例：角色三视图附大脸特写、盔甲和战斗动作。修正：当前只交同角色基础三视图，其他用途独立处理。

检查身份固定项、全身比例、手脚可见性、侧背一致性。更细的脸部/毛发/接触问题，可按本轮目录读取 face-expression、hair-grooming、pose-contact；无需三个全读。
