# 场景、外景与建筑外观

先区分环境定稿空镜与剧情镜头。空镜资产锁定地形、道路、出入口、地标与表演区；剧情镜头才按分镜安排人物和动作。仅写“宏大、电影感”容易得到拥挤海报，补充明确的空间关系。

- 布局：前景用边缘树枝、墙角等建立纵深，中景保留行动区域，远景用建筑轮廓/地形交代位置；不用每层都塞满高对比细节。
- 建筑：用途、时代地域、体量、屋顶和入口形状、主体材料、关键开窗和外部通路。悬疑旧楼、校园、古镇、空间站分别取当前需求，不能默认金色巨殿。
- 光色：时间、主光方向、天气、空气清晰度；潮湿材质写实际积水位置与反射来源，雨雾强度不遮没道路。季节变化保持布局，仅替换必要植被/积雪/光照。
- 连续性：已有定稿作为真实参考，指定机位相对入口、道路或地标的位置；“换到门内向外看”与“把图片左右翻转”不同。俯视布局图有助理解但只在本任务确实需要时制作，不强制九宫格或鸟瞰起步。

示例：现代校园后门外的无人巷道，摄影机朝向尽头铁门；左侧砖墙，右侧低矮自行车棚，中间留一条完整步行通道，远处教学楼只露顶部。阴天雨后，地面局部积水反射灰白天空，入口和巷道转角清晰；二维动画背景，平视广景，一张完整画面。

奇幻改写思路：以石阶、断桥、浮岛落点建立交通关系，悬浮结构只按世界设定存在；体量感通过阶梯/门洞尺度表达，不必加无关小人。荒漠、雪原或太空以地平线/轨道结构和层次表达距离。

反例：换个角度后铁门和车棚互换，增加并不存在的出口。修正：引用定稿，固定拓扑和地标，只改变观察机位。检查可行动面积、入口数量、尺度、天气/光向及后续镜头衔接。
