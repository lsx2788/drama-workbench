# 动物、怪物与机械生物

先写身体结构，再写风格和装饰：头躯比例、四肢/翅/尾数量、关节方向、移动方式、表皮或毛鳞羽的分区。现实动物按物种依据，虚构生物按已确认设定；不能因为叫“萌宠”就自动改成人脸或幼年。

姿态选自然站立、栖停或一个动作瞬间。全身资产露出主要肢体，遮挡部分以实际可见性检查。毛发沿体块生长，鳞片随弯曲变化，机械部件保持铰接连续；不要把金属、毛皮和透明晶体随机涂在同一处。

补视图引用已定稿基准，保留耳角形状、花纹位置、眼色、伤痕及体型。默认单视图；不要擅自套用人类白色打底服和人形 A-pose。如果系统用途不支持此类基准，按实际通道说明，不伪装为人类任务。

示例：二维奇幻短剧的成年沙漠驮兽，低重心四足，厚颈、小圆耳、宽蹄，浅褐短毛，肩部深褐斑块；自然侧向站立，头轻转向镜头，四足着地，单色沙灰背景，干净线条与块面阴影；不带鞍具，当前只确认生物形象。

反例：正面是四足兽，换角度后变成六足或多出尾巴。修正：在基准与图中逐项核对身体结构，必要时局部返修，不用烟雾掩盖。鞍具和正式骑乘属于不同用途，按实际任务另处理。
