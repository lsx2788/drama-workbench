# 短剧文生图审核

围绕本任务用途和实际原图判断。按图种读取相关章节，章节示例不是额外验收门槛：

- 人物：[characters.md](references/characters.md)；衣装：[costumes.md](references/costumes.md)。
- 外景：[environments.md](references/environments.md)；室内：[interiors.md](references/interiors.md)。
- 装备：[equipment-props.md](references/equipment-props.md)；载具：[vehicles.md](references/vehicles.md)；生物：[creatures.md](references/creatures.md)。
- 特效：[effects.md](references/effects.md)；静帧：[shot-frames.md](references/shot-frames.md)；插入图：[graphic-inserts.md](references/graphic-inserts.md)。

1. 用途与基准：是否交错图种、混合拼版、改变身份/布局/剧情事实；已引用文件是否真实且当前可用。定稿图不能代替规范图；文字描述不能代替已生成文件。
2. 可见证据：关键结构、数量、相对位置、接触关系和材质是否足以支撑当前镜头。看不清的背面或细字标为不可验证，不想象补全。通过统一描述不能证明几何精确或多角度完全一致。
3. 可制作性：基础参考是否被烟雾、黑暗、景深掩盖；镜头静帧是否有明确主体与动作瞬间；宽高比、像素、alpha 等核对真实文件。
4. 反馈分主次：先给通过/修改/询问及主要原因，再列定位明确的缺陷、需要修改与必须保留的内容。只列影响需求、身份连续性和后续制作的问题，不因为参考章节提到额外视角就强制补图。

总控按既有权限判断关键方向和整包是否可用，补图审核仍由对应资产审核 AI 执行。技术失败说明真实原因，由系统既有通道转交；不要向用户重新询问已经批准的事情。
