# 结构方法与题材适配

先看任务长度、叙事目标和原作，再选一种主方法，不叠加所有模板。

| 方法                | 适合解决的问题               | 使用限制                         |
| ------------------- | ---------------------------- | -------------------------------- |
| 一句话故事          | 核对主体、目标、阻碍与代价   | 意境或知识短片不必强套主角对抗   |
| 故事节拍表          | 找出事件与情绪变化、调整顺序 | 节拍不等于镜头；数量由内容决定   |
| 起因—推进—收束/三幕 | 检查准备、变化和结果         | 不是固定秒点、页码或固定集数     |
| 场景提纲            | 检查每场是否推进事实或关系   | 简介不等于已经完成剧本           |
| 人物变化线          | 维护选择与代价的积累         | 角色可以坚持原则，不强迫人人反转 |

悬疑：区分真相、线索、角色猜测、观众所知，反转不能靠事后新造关键事实。喜剧：建立预期再变化，保持人物动机；不要为笑点破坏世界规则。情感/家庭：关系变化通过选择与行为累积，不自动升级为背叛或暴力。动作：明确目标、障碍、空间结果，战斗不只是形容词。奇幻/科幻：把规则与代价放进情节，不临时新增万能能力。知识/展示短片：按问题、解释、示例和收束组织，不能把推测包装成事实。

保持已确认受众、基调和改编尺度。题材只是选择方法的依据，不是自动新增情节、人物数量或“爆款”承诺。
