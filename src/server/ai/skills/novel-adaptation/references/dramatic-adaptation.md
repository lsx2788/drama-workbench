# 从叙述到戏剧行动

用“原文功能 → 新场景怎么让观众获得它 → 改动与代价”记录重要改编。

例如原文一段“她不再信任师父”的心理描述，可转为她把原本准备递出的信收回，改说另一句话；必须有前置事件支持这种选择。不能仅为视觉化新增背叛事实，也不能把每个心理句机械改成眨眼握拳。

处理信息的几个常用方式：行动结果暴露事实、人物为目标交锋时透露信息、环境或道具提供线索、必要的简短旁白。选择符合人物和当前观众知识的方式；说话双方都知道的信息不必为观众整段复述。

合并角色/场景须检查四项：剧情功能、人物立场、信息持有、关系后果。把两个送信者合并可能可行，把互相不知情的阵营负责人合并会改变核心谜题。后一类提出方案而非自行落实。

取舍表只记重要变化：原位置、保留功能、压缩/替换方法、影响、确认依据。不为所有标点改动建记录，也不把完整原文搬进报告。

场景提纲可用“地点与时间；人物目标；阻碍；行动；场末变化”。后续展开对白仍应服务于行动，不以丰富词藻代替剧情。
