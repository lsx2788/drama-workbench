# 改编剧本审核

先核对本轮交付范围、原作理解和确认需求，不以“更忠实”或“更戏剧化”单方面替换用户选择。

1. 主因果是否成立：动机、选择、结果与重要信息来源可追踪；删合段落是否造成无缘由的关系变化。
2. 视听表达是否成立：关键剧情能通过行动和声音呈现，而非大量不可见心理结论。
3. 取舍是否透明：新增、合并、删减与原作事实分开；重大改写是否已有依据。
4. 职责是否正确：编剧不替分镜定镜头数/运镜，不把框架或估算说成已完成全本/实测时长。

需要时读 [改编细节](references/dramatic-adaptation.md) 或 [结构适配](references/genre-structure.md)。给最少但可执行的返修意见，保留有效内容；方法模板不作为新增门槛。
