# 人物定稿与规范图
## 输入依据
角色设定、已确认年龄阶段/体型/画风、当前 imageSpec 的 purpose 和 basisTaskId；存在基准时先看真实原图。
## 制作方法
首样锁定脸型、五官比例、发际线、体型与画风；不因美化改变年龄、性别表现、肤色或体型。人形基础图使用项目要求的不透明白色基础打底服，中性 A-pose，头脚完整，四肢轮廓清楚，不带剧情服饰和道具。
三视图只展示同一角色的正、正侧、背，等尺度、同地面基线、同姿态和稳定布光。按画面可见性核对相同的发型、耳部、体块比例；侧面不能是另一个人的脸。
面部特写另建用途，不能在规范三视图旁再拼服装、武器和多个特写。三视图通过后按原流程单独找服装，再引用三视图与服装图做穿衣组合。
非人类或特殊体态以已确认解剖为准，有系统用途不适配时说明差异，不偷偷绕过门控。
## 输出与检查
说明身份固定项、当前视图与真实参考、保持项和本轮变化。仅当前用途所需，不自动扩成全角色图集。
## 正反例
正例：已确认的中年壮年男性，三视图保留肩宽、腹部体块及发际线；写实/动画分别沿用原画风。
反例：把同角色老年图修成年轻瘦脸，或三视图继承礼服长裙。修正：保持年龄与体型，基础服只为辨识身体结构。


## 审核入口

独立审核时使用 [审核要点](review.md)。网页执行链按当前身份自动返回制作或审核内容。
