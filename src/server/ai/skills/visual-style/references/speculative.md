# 科幻、奇幻与非人角色
科幻先讲结构用途：机械关节、外壳分块、软硬连接、穿戴接触与尺度；光源和能量部件说明位置与范围，不能整身随意发光。
奇幻先定义稳定识别特征，再加有依据的特殊材料或效应。仙侠、魔法、蒸汽或未来科技不是默认混搭许可。特效不能遮住需要确认的脸、手、脚或道具接触。
非人角色沿用既定解剖（肢体数量、关节、翼尾位置、毛皮/鳞甲），不机械强加人类五指或真人皮肤。动物、机器人不套人类白色长袖长裤；若工具用途或现有规范仅支持人形，应说明适用差异交节点审核判断，不能改用途绕过系统约束。
三视参考保持同一结构、尺度与中性姿态；只有任务明确的人形基础图才采用既定白色打底服 A-pose。
审核以明确的世界设定和可见结构为证据，不以“现实不存在”拒绝已授权虚构设计，也不接受无法解释的随机增肢和部件漂浮。
