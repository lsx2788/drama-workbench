# 现代、历史与文化题材
现代按职业、场合、季节、活动需求和身份选择廓形、穿戴方式与磨损；不把都市统一为礼服或奢侈品牌。男性、女性、不同年龄和体型沿用角色基准，不靠缩腰、美白、减龄统一美化。
历史题材区分原文明示、可靠图像资料与自由设计。中国古代、欧洲历史、其他地区的衣装分别按已确定文化和时期取用；领型、腰线、袖型、扣结和层叠关系比“古风”更可执行。不凭网络发型名称或二次转载图就保证朝代准确。
虚构世界可受某时期启发，但要说明是设计借鉴；不能把各时期服饰与其他文化符号无依据堆在一起。
正式衣物按项目既定角色→规范图→独立服装→穿衣组合顺序。题材差异不改变白色基础打底服的用途。
审核只检查本任务明确的时代/文化要求、结构与身份适配；未要求历史复原时不添加考据门槛。
