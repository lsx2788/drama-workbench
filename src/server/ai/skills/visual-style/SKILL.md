# 题材与画风
## 输入依据
已确认的项目风格、角色与环境参考、本次图种。把“表现什么”（时代、文化、世界设定）与“怎么表现”（真人写实、三维、二维、插画）分开。
## 制作方法
先锁主体身份、比例与用途，再选择一致的轮廓、线条、材质和光影语言。现代、历史、科幻、奇幻都能采用不同媒介；混合风格应说明哪个层面借用哪种语言，不能把不相容的词平铺堆叠。
无明确方向时沿用项目已有基准；尚未确定的重大方向走原有询问渠道。不能因范例好看把所有角色改成东亚少女、尖脸、大眼、白皮或同一身材。
参考图逐项注明锁身份、服装、材质或光线，实际调用传真实文件编号。风格参考中的脸、物件、文字排版不自动带入。
## 按需参考
- [写实与影视 CG](references/realistic.md)：实际使用写实摄影、影视级 CG、写实三维时读取。
- [二维、三维动画与插画](references/animation.md)：实际使用赛璐璐、卡通、绘本、水彩或风格化三维时读取。
- [科幻、奇幻与非人角色](references/speculative.md)：有虚构结构、机械、异种或魔法材质时读取。
- [现代与历史题材](references/period-modern.md)：服装、时代、职业、文化来源影响视觉设定时读取。
只读取任务真正适用的参考，不默认全读。
## 正反例
正例：现代都市人物，二维赛璐璐；保留既定成年男性的面部比例，使用清楚线条和有限阴影色块。
反例：现代题材自动变成真人照片，或给所有角色套“18岁白皙美少女”。修正：题材和媒介分别锁定。
## 检查要点
主体辨识与媒介一致；没有把审美样例冒充已确定身份；一图只有当前用途。
