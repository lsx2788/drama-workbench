# 服装与材质
## 输入依据
既定角色、场合/时代/职业、服装参考和实际材质参考；用途是服装单图、穿衣组合还是局部返修。
## 制作方法
分开写廓形/剪裁、层次/扣结、材质、配色、纹样。现代日常看合体余量与活动褶皱；职业服看用途与穿戴关系；历史服装看领型袖型腰线与图像依据；科幻/奇幻看软硬连接和穿戴接触，不自动加发光线路或满身金饰。
纱写边缘透光与垂坠，内层覆盖不透明；缎面亮带沿褶皱，棉麻哑光适度织纹，皮革区分柔软折痕与挺括支撑，金属看硬边与局部高光。橡胶/塑料按需求区分粗糙度，不给所有材质相同镜面光泽。
纹样写衣片位置、大小、疏密与走向；袖口刺绣不能自行铺满全身。材质参考只提供目标部位的织纹/光泽/厚薄，不继承模特、款式和背景；款式图不能证明真实织纹。
独立服装不带人物；穿衣组合使用已验收角色三视图和独立服装真实原图。衣料随体型自然穿着，不为衣服换脸或瘦身。基础打底服不套正式衣装技巧。
## 正反例与检查
正例：保留夹克剪裁与颜色，只调整肘部过硬褶皱；皮革参考只用于该夹克材质。
反例：“更轻盈”直接开低领、改裙长、加透明贴身衣。修正：余量、垂坠、光泽等可见变化，重大设计改动按原审批边界。
